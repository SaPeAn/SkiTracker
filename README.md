# SkiTracker — GPS-трекер для беговых лыж

Плата: TTGO T-Display (ESP32). GPS: NEO-6M (позже NEO-M8N). Пульсометр: Coospo H6M (BLE).

## Подключение GPS

| GPS  | T-Display |
|------|-----------|
| VCC  | 3V3       |
| GND  | GND       |
| TX   | GPIO 25   |
| RX   | GPIO 26   |

Пины 4, 5, 16, 18, 19, 23 заняты экраном. Барометр позже: SDA — 21, SCL — 22.
NEO-M8N подключается так же, прошивку менять не нужно.

## Сборка и прошивка

1. VS Code → Extensions → установить **PlatformIO IDE**.
2. File → Open Folder → эта папка. PlatformIO сам скачает библиотеки.
3. Подключить плату по USB-C, внизу нажать **→ (Upload)**.
4. **🔌 (Serial Monitor)** — раз в секунду выводится строка состояния GPS и пульса.

Настройки (пины, часовой пояс, частота GPS, пароль Wi-Fi) — в `include/config.h`.

## Кнопки

| Действие | Кнопка |
|---|---|
| Следующий экран (основной / статус / сигнал GPS) | правая коротко |
| Старт / стоп записи | правая долго (1.5 с) |
| Выключить экран | левая коротко |
| Выгрузка по Wi-Fi вкл/выкл | левая 1.5 с и отпустить |
| **Выключить** (трек сохраняется) | левая 4 с |
| **Включить** | правая 2 с |
| Забыть пульсометр | обе 4 с |

Выключение «мягкое»: ESP32, GPS и экран засыпают, но батарея остаётся подключённой.
Для хранения дольше пары недель — выключатель на проводе батареи.

Запись стартует сама при первом фиксе GPS (`AUTO_START_ON_FIX`). Экран гаснет через 60 с,
первое нажатие его только включает.

## Первая проверка

**GPS.** На экране статуса (правая кнопка):
- `GPS: NO DATA` — нет байтов от модуля: проверьте TX модуля → GPIO 25 и питание.
- `UBX no ack` — данные идут, но модуль не принял настройки: проверьте RX модуля → GPIO 26
  (или модуль — клон; работать будет с настройками по умолчанию).
- Фикс на улице: холодный старт 30–60 с, затем `Fix: yes` и число спутников.

**Сигнал GPS** (третий экран): столбик — спутник, высота — C/N0 в дБГц. Зелёный ≥ 35, жёлтый 25–34,
красный ниже. `top4` — средний по четырём лучшим. Для координат нужно минимум 4 уверенных спутника.

**Пульсометр.** Наденьте и смочите ремень, держите рядом с платой (< 1–2 м).
Плата подключится к ближайшему ремню и запомнит его — дальше будет подключаться только к нему.
Если ремень уже подключён к часам/телефону по Bluetooth, отключите их от ремня.

## Батарея

LiPo 3.7 В (1500–2000 мАч, с платой защиты) — в разъём JST 1.25 мм. **Проверьте полярность!**
Заряд — через USB-C, только в тепле (выше 0 °C). Выключатель лучше поставить в разрыв «+».

- ниже 3.55 В — индикатор батареи мигает красным, экран включается с надписью `LOW BATTERY!`
  (повтор раз в 5 минут);
- ниже 3.40 В (15 секунд подряд) — трек сохраняется, GPS, экран и ESP32 засыпают;
- разбудить — правой кнопкой (если батарея всё ещё пустая, трекер сразу уснёт снова).

Пороги — в `include/config.h` (`BAT_WARN_V`, `BAT_SHUTDOWN_V`).

## Выгрузка треков

Левая кнопка долго (запись должна быть остановлена) → подключиться к Wi-Fi `SkiTracker`
(пароль `skitrack123`) → открыть `http://192.168.4.1`. Там список треков: GPX (с пульсом,
подходит для Strava / Garmin Connect), CSV, удаление.

Формат CSV: `time_utc,lat,lon,alt_m,speed_kmh,hr_bpm,sats,hdop`, одна строка в секунду.
Памяти хватает примерно на 8 часов записи.

## Приложение для Android

Готовый файл — `SkiTracker.apk` (Android 7.0 и новее), исходники — `android/`.

1. Скопировать APK на телефон, открыть, разрешить установку из этого источника.
2. На трекере: остановить запись (правая 1.5 с), включить Wi-Fi (левая 1.5 с и отпустить).
3. В приложении: «Загрузить с трекера» → «Подключиться». Android 10+ сам предложит сеть SkiTracker;
   на Android 9 и старше к ней нужно подключиться вручную в настройках Wi-Fi.
4. Скачать треки. Просмотр работает без трекера; для подложки карты нужен интернет (OpenStreetMap).

Если изменили `WIFI_AP_SSID` / `WIFI_AP_PASS` — поменяйте их и в приложении («Сеть трекера»).

Пересборка: `android/build-apk.ps1`. Инструменты и ключ подписи — в `C:\Android-build`.
Ключ `C:\Android-build\keystore` сохраните: без него обновление не установится поверх старой версии.
